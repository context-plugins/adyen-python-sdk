
# Three DS 1 Result

## Structure

`ThreeDS1Result`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `cavv` | `str` | Optional | The cardholder authentication value (base64 encoded). |
| `cavv_algorithm` | `str` | Optional | The CAVV algorithm used. |
| `eci` | `str` | Optional | 3D Secure Electronic Commerce Indicator (ECI). |
| `three_d_authenticated_response` | `str` | Optional | The authentication response from the ACS. |
| `three_d_offered_response` | `str` | Optional | Whether 3D Secure was offered or not. |
| `xid` | `str` | Optional | A unique transaction identifier generated by the MPI on behalf of the merchant to identify the 3D Secure transaction, in `Base64` encoding. |
