
# Payment Details 1

The details of the payment. You must show your user these details before they confirm or cancel the payment.

*This model accepts additional fields of type Any.*

## Structure

`PaymentDetails1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `amount` | [`Amount`](../../doc/models/amount.md) | Required | - |
| `counterparty` | [`Counterparty`](../../doc/models/counterparty.md) | Required | - |
| `description` | `str` | Required | The description for the payment. It is generated by the payment method, such as iDEAL, and should be shown to the user. |
| `expires_at` | `datetime` | Required | The expiration date of the payment in ISO DateTime format, as described on ISO 20022 (YYYY-MM-DDThh:mm:ss.sss+/-hh:mm).<br><br>Example: **2025-12-30T14:15:30+01:00** |
| `additional_properties` | `Dict[str, Any]` | Optional | - |

## Example

```python
import dateutil.parser
import jsonpickle

from adyen.models.account_holder import AccountHolder
from adyen.models.account_identification_1 import AccountIdentification1
from adyen.models.amount import Amount
from adyen.models.counterparty import Counterparty
from adyen.models.payment_details_1 import PaymentDetails1

payment_details_1 = PaymentDetails1(
    amount=Amount(
        currency='EUR',
        value=499,
        additional_properties={
            'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
        }
    ),
    counterparty=Counterparty(
        account_holder=AccountHolder(
            full_name='John Doe',
            additional_properties={
                'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
            }
        ),
        account_identification=AccountIdentification1(
            mtype='AccountIdentification1',
            additional_properties={
                'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
            }
        ),
        additional_properties={
            'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
        }
    ),
    description='Payment at MyShop. ref:12345678',
    expires_at=dateutil.parser.parse('2025-12-30T14:15:30+01:00'),
    additional_properties={
        'exampleAdditionalProperty': jsonpickle.decode('{"key1":"val1","key2":"val2"}')
    }
)
```
