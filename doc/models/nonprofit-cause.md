
# Nonprofit Cause

## Structure

`NonprofitCause`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `banner_url` | `str` | Required | The URL to the banner of the cause. |
| `description` | `str` | Required | The description of the cause. |
| `id` | `str` | Optional | The unique identifier of the cause. This value is generated by Adyen. |
| `locales` | `List[str]` | Required | The locales that the cause supports, in [IETF BCP 47](https://en.wikipedia.org/wiki/IETF_language_tag) format. |
| `name` | `str` | Required | The name of the cause. |

## Example

```python
from adyen.models.nonprofit_cause import NonprofitCause

nonprofit_cause = NonprofitCause(
    banner_url='bannerUrl6',
    description='description4',
    locales=[
        'locales4'
    ],
    name='name4',
    id='id4'
)
```
