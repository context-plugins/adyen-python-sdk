
# Secure Remote Commerce Checkout Data 2

Checkout data for a Secure Remote Commerce payment.

## Structure

`SecureRemoteCommerceCheckoutData2`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `checkout_payload` | `str` | Optional | The Secure Remote Commerce checkout payload to process the payment with.<br><br>**Constraints**: *Maximum Length*: `10000` |
| `correlation_id` | `str` | Optional | This is the unique identifier generated by SRC system to track and link SRC messages. Available within the present checkout session (e.g. received in an earlier API response during the present session).<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `40` |
| `cvc` | `str` | Optional | The [card verification code](https://docs.adyen.com/get-started-with-adyen/payment-glossary/#card-security-code-cvc-cvv-cid).<br><br>**Constraints**: *Minimum Length*: `1`, *Maximum Length*: `20` |
| `digital_card_id` | `str` | Optional | A unique identifier that represents the token associated with a card enrolled. Required for scheme 'mc'.<br><br>**Constraints**: *Maximum Length*: `80` |
| `scheme` | [`SchemeEnum`](../../doc/models/scheme-enum.md) | Optional | The Secure Remote Commerce scheme. |
| `token_reference` | `str` | Optional | A unique identifier that represents the token associated with a card enrolled. Required for scheme 'visa'.<br><br>**Constraints**: *Maximum Length*: `80` |
