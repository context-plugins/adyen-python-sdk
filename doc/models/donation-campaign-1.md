
# Donation Campaign 1

## Structure

`DonationCampaign1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `account_holder_ids` | `List[str]` | Optional | The unique identifiers of the account holders associated with the donation campaign. |
| `activated_at` | `datetime` | Optional, Read-only | The date and time when the campaign started, in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format. For example, 2026-06-18T10:28:59.820+00:00 |
| `ended_at` | `datetime` | Optional, Read-only | The date and time when the campaign stopped, in [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) format.  For example, 2026-06-18T10:28:59.820+00:00. |
| `id` | `str` | Required, Read-only | The unique identifier of the donation campaign. This value is generated by Adyen. |
| `in_person` | [`InPersonDonationSettingsResponse2`](../../doc/models/in-person-donation-settings-response-2.md) | Optional | The settings for in-person donations collected as part of the campaign. |
| `name` | `str` | Required | The name of the donation campaign. |
| `nonprofit_cause` | [`DonationCampaignNonprofitCause2`](../../doc/models/donation-campaign-nonprofit-cause-2.md) | Required | The nonprofit cause that the campaign supports. |
| `online` | [`OnlineDonationSettingsResponse2`](../../doc/models/online-donation-settings-response-2.md) | Optional | The settings for online donations collected as part of the campaign. |
| `status` | [`DonationCampaignStatus2Enum`](../../doc/models/donation-campaign-status-2-enum.md) | Required | The current status of the donation campaign. |
