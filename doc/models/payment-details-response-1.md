
# Payment Details Response 1

## Structure

`PaymentDetailsResponse1`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `details` | [`PaymentDetails11`](../../doc/models/payment-details-11.md) | Required | The details of the payment. You must show your user these details before they confirm or cancel the payment. |
| `token` | `str` | Required | The token that identifies the payment. It is generated by Adyen and is needed to confirm or cancel the payment.<br><br>**Constraints**: *Minimum Length*: `1` |

## Example

```python
import dateutil.parser

from adyen.models.account_holder_11 import AccountHolder11
from adyen.models.account_identification_1 import AccountIdentification1
from adyen.models.amount_110 import Amount110
from adyen.models.counterparty_11 import Counterparty11
from adyen.models.payment_details_11 import PaymentDetails11
from adyen.models.payment_details_response_1 import PaymentDetailsResponse1

payment_details_response_1 = PaymentDetailsResponse1(
    details=PaymentDetails11(
        amount=Amount110(
            currency='EUR',
            value=499
        ),
        counterparty=Counterparty11(
            account_holder=AccountHolder11(
                full_name='John Doe'
            ),
            account_identification=AccountIdentification1(
                mtype='AccountIdentification1'
            )
        ),
        description='Payment at MyShop. ref:12345678',
        expires_at=dateutil.parser.parse('2025-12-30T14:15:30+01:00')
    ),
    token='ewoJIlNvbWVUb2tlbiIgOiAiU29tZUluZm8iCn0='
)
```
