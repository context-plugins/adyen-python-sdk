
# Nonprofit

`Nonprofit`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `causes` | [`List[NonprofitCause]`](../../doc/models/nonprofit-cause.md) | Required | The causes that the nonprofit supports.<br><br>**Constraints**: *Minimum Items*: `1` |
| `description` | `str` | Required | The description of the nonprofit. |
| `goals` | `List[str]` | Required | The goals of the nonprofit.<br><br>**Constraints**: *Minimum Items*: `1` |
| `id` | `str` | Optional | The unique identifier of the nonprofit organization. This value is generated by Adyen. |
| `locales` | `List[str]` | Required | The locales that the nonprofit supports, in [IETF BCP 47](https://en.wikipedia.org/wiki/IETF_language_tag) format.<br><br>**Constraints**: *Minimum Items*: `1` |
| `logo_url` | `str` | Required | The URL to the logo of the nonprofit. |
| `name` | `str` | Required | The name of the nonprofit. |
| `regions` | `List[str]` | Required | The regions where the nonprofit operates, in [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) format.<br><br>**Constraints**: *Minimum Items*: `1` |
| `terms_and_conditions_url` | `str` | Required | The URL to the terms and conditions of the nonprofit. |
| `website` | `str` | Required | The URL to the website of the nonprofit. |
